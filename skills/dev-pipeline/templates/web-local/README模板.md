# <应用名> · 使用说明（网页版）

## 这是什么

<一句白话：一个记账小网页，打开就能记，数据存在浏览器里。>

## 怎么打开

- 双击 `index.html`。推荐用 Edge/Chrome。
- 如果双击没有反应：右键 →「打开方式」→ 选择 Edge/Chrome。

## 怎么用

1. 填金额、备注，点「保存」。
2. 列表里能看到记录，右上角是结余。
3. 点「导出备份」会把数据存成一个 JSON 文件；换电脑/清浏览器前先导出。
4. 点「导入备份」可以选之前导出的 JSON 恢复。

## 数据在哪 / 怎么备份

- 数据存在浏览器的 localStorage 里，不在文件旁边。
- 清浏览器数据、换浏览器、换电脑都可能丢；重要数据请定期「导出备份」。
- 恢复：打开网页 →「导入备份」→ 选择 JSON。

## 自验清单

1. 双击 index.html，能看到记账页面。
2. 记一笔 12.50，列表出现。
3. 关掉浏览器，重新打开，记录还在。
4. 导出备份，能看到下载的 JSON 文件。

## 已知限制

- 只适合不敏感、数据量不大的记录；重要数据建议用桌面版。
- 不同浏览器/不同电脑的数据不互通；靠导出/导入迁移。
- 没有登录、没有云同步。

## 卸载

删除 `index.html`、`app.js`、`styles.css` 即可；浏览器里的数据可在浏览器设置里清除。
