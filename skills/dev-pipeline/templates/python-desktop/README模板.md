## 怎么打开

- 双击：`<成品 exe 路径>`，或桌面上的「<应用名>」快捷方式。
- 如果 Windows 提示「已保护你的电脑」：点「更多信息」→「仍要运行」。这是因为程序没有购买签名证书，不是病毒。
- 没有打包版时：双击 `启动.bat`（需要电脑上装了 Python 3.10+）。

## 怎么用

1. 在「金额」里填数字，例如 `12.50`；在「备注」里写一句，例如「午饭」。
2. 点「保存」，下面列表会出现这一笔，右上角结余会更新。
3. 点「备份数据」会把当前数据复制一份到数据文件夹的 `backups` 里。
4. 关掉程序再打开，记录还在。

## 数据在哪里

- 数据文件夹：`<%LOCALAPPDATA%\<应用名> 的完整路径>`
- 里面 `data.db` 是全部数据；`backups` 是自动/手动备份；`logs` 是日志。
- 备份：点程序里的「备份数据」，或关闭程序后把整个数据文件夹复制到 U 盘/网盘。
- 恢复：先关闭程序，把备份文件复制回数据文件夹并改名为 `data.db`，再打开程序。

4. 点「备份数据」，能在数据文件夹的 `backups` 里看到新文件。
