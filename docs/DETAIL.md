# 开发者模式

**开发者模式**是 dsh-dev-mode 为 DeepSeek Harness 增加的 agent 预设。不懂编程的用户用几句话讲需求，代理按七个阶段把需求变成**真跑过、数据安全、带中文说明**的程序。

## 它适合什么

- 想做一个小工具、小脚本、本地网页或 Windows 桌面程序，但自己不会编程。
- 有一个旧程序想改，希望先备份、改完做回归、数据不丢。
- 需要的不只是「代码」，而是能双击打开、有说明书、能自己验证的成品。

## 怎么用

1. 安装后在**新会话**选择「开发者模式」。
2. 用大白话说要什么，例如「帮我做个记账小工具，记一笔／看明细／看结余／关掉重开数据还在」。
3. 代理最多问一轮，然后自动选做法、写计划、派后台执行器写代码、独立测试、打包。
4. 最后交付成品、中文说明、验收表和自检清单。

设置里的「开发者模式·执行器」是自动调用的后台角色，不用手动选择。

## 七个阶段

接单分级 → 环境选型 → 规格计划 → 垂直切片 → 分批实现 → 独立验收 → 打包交付。

小事走 L0 快线（直接改），普通任务走 L1（执行器 + 独立测试），多文件/有数据/要打包/改旧程序走 L2（加计划评审、垂直切片和干净环境安装测试）。

## 它保证什么

- 每条验收标准都有「怎么验 + 结果 + 证据」；没验到的写 `BLOCKED`，不假装通过。
- 有数据时证明「关掉再打开数据还在」，并给备份/恢复办法。
- 交付前从最终位置启动，不依赖开发命令。
- 未签名 exe 的 SmartScreen 提示会在手册里解释。
- 过程记录在工程目录 `.dsh-dev/`，可删，不影响程序使用。

## 环境要求

- DSH 0.2.2 及以上（实测 `0.2.2-rc.3`）。
- 插件本身不需要额外运行时；生成的程序按本机实际有的运行时选型（Python 3.10+ / Node / 本地网页）。
- 当前主要在 Windows 10/11 实测。

## 已知限制

- GUI 的复杂鼠标操作可能无法自动验证，会标 `BLOCKED` 并给人工自检步骤。
- 登录/支付/服务器类大系统会先做最小可用版本，再分阶段。
- 权限由部署方决定；受限权限下后台执行器可能无法启动命令或写工作目录以外的位置。
- 非 Windows 平台与插件详情页渲染未实测。

安装、升级、排错与维护者验证见仓库 README。
